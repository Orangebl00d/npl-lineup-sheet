# NPL Lineup Sheet — USA Team League Spring 2026

Fillable, phone-friendly version of the National Padel League lineup sheet.

- Fill in teams, captains, date/time, category, venue, and 3 matches
- Tap the winning team per match; running match tally
- Both captains sign on screen
- **Share lineup** sends a PDF laid out like the paper sheet (text, AirDrop, email); **PDF** downloads it; **Copy text** copies a plain summary
- Everything autosaves on the device (localStorage); nothing is sent to a server

Static site, hosted on GitHub Pages.
